# Text-to-Speech Application - Frontend

This is the frontend client for the Text-to-Speech (TTS) web application built with **React.js**. It provides an interactive user interface to convert written text into natural-sounding speech by communicating with a backend Node.js and Express API.


## 🚀 Features

* **Text Input:** Enter or paste text with real-time character count and validation.
* **Language Selection:** Choose from multiple supported languages.
* **Voice Selection:** Select from available voice options and styles.
* **Speech Generation:** Send text and voice configurations to the backend REST API[cite: 1].
* **Audio Player:** Play, pause, seek, and manage volume for generated audio[cite: 1].
* **Download Audio:** Download generated speech as an audio file[cite: 1].
* **Error Handling:** Gracefully display validation errors, network failures, and API errors[cite: 1].
